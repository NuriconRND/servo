# GStreamer 1.28.4.100 마이그레이션 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Servo 번들 GStreamer를 1.22.8에서 사내 커스텀 **1.28.4.100**으로 전면 전환하고(현재 브랜치 `nonstandard-media-display-port`), 기존 미디어 기능(P1~P4 + 월 + 캡처카드) 무회귀를 검증한다.

**Architecture:** 해석은 전부 `gstreamer_root()`(windows.py:138) 한 곳에서 갈림(슬롯#1 → env var → C:\gstreamer). 로컬 설치(F:)를 env var로 가리키고 워크트리 슬롯#1을 그 설치로 **정션**해 컴파일·DLL복사·런타임을 1.28.4.100으로 통일한다. 커밋 대상 코드 변경은 `gstreamer.py`(DLL 이름) + `windows.rs.in`(카메라 소스 플러그인)뿐. 나머지는 머신 상태(env var/정션/로컬설치, 비커밋).

**Tech Stack:** GStreamer 1.28.4.100(FFmpeg 7 / OpenSSL 3), Servo(Rust/Cargo), `mach`(Python), PowerShell, Windows.

## Global Constraints

- 빌드는 **full `mach build`(no `-p`)** 필수 — `cargo build -p servoshell`은 `media-gstreamer` 피처 누락(더미 백엔드). env 소싱 후 `$ErrorActionPreference='Continue'`.
- 미디어/월 **표출 검증은 release 빌드** 필수(debug는 webrender GL 에러체크가 DComp/AMD `invalidate_framebuffer`를 패닉 승격; release는 미실행). release 최종 링크는 lld-link 우회: `$env:CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_LINKER`를 MSVC `link.exe` 풀경로로.
- `PKG_CONFIG_PATH`는 **forward-slash**(1.28.x lld-link `could not open 'gstreamer-1.0.lib'` 함정). `servo_env.ps1`에 이미 반영 — 재확인만.
- 프로브 실행: 페이지는 **절대 `file:///` URL**(상대경로 = 프록시 라우팅 "Error loading page"). 로그는 `Start-Process -RedirectStandardOutput/-RedirectStandardError`로 캡처(native stdout·UTF-16 grep 함정 회피).
- `mach bootstrap-gstreamer` **실행 금지**(슬롯#1에 1.22.8 재설치).
- 워크트리 절대경로: `F:\20260609_SDWall_BrowserTest\20260606_multigpu_browser\servo_multigpu-tiled-wall` (subst `W:` = 리포 루트).
- 로컬 설치 경로: `F:\gstreamer-inhouse\1.28.4.100\1.0\msvc_x86_64`.
- 공유 소스: `\\192.168.1.214\share\NuriconCommon\gstreamer\1.28.4.100\msvc_x86_64`.
- 설계 스펙: `docs/superpowers/specs/2026-07-22-gstreamer-1.28.4-migration-design.md`.
